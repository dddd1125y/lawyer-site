# 카페 계절 — 소상공인 홈페이지 데모

크몽·숨고 대표 포트폴리오로 쓰기 위해 만든 **1페이지 카페 홈페이지 데모**입니다.
"카페 계절"은 실제로 운영되는 매장이 아니라, 소상공인 홈페이지가 어떤 모습이어야 하는지
보여주기 위해 만든 가상의 매장입니다. (페이지 곳곳에 데모임을 명시해 두었습니다.)

빌드 도구 없이 HTML·CSS·바닐라 JS만 사용하므로 파일을 그대로 올리면 바로 서비스됩니다.

```
portfolio/cafe-gyejeol/
├── index.html                  전체 페이지 (8개 구획)
└── assets/
    ├── favicon.svg             사계절 마크
    ├── css/cafe.css            디자인 시스템 + 계절 컬러 토큰
    └── js/cafe.js              ★ 메뉴 데이터 + 영업 상태 로직
```

## 화면 구성

| # | 구획 | 목적 |
|---|---|---|
| 01 | 헤더 | 스크롤해도 상호와 메뉴가 따라옴 |
| 02 | 히어로 | **지금 영업 중인지**를 첫 화면에서 즉시 확인 |
| 03 | 이야기 | 계절마다 메뉴를 바꾸는 이유 = 재방문 동기 |
| 04 | 메뉴 | 계절 탭 전환 + 상시 메뉴 가격표 |
| 05 | 공간 | 좌석 도면으로 "자리 있나요?" 문의를 줄임 |
| 06 | 오시는 길 | 지도 + 요일별 영업시간(라스트오더 포함) |
| 07 | 제작사 밴드 | WEB·BUILD 소개 · 가격/기간 안내 (시각 언어를 바꿔 카페 영역과 분리) |
| 08 | 푸터 | 데모 고지 |

모바일에서는 화면 하단에 **"이번 계절 메뉴 / 길찾기"** 고정 바가 항상 붙어 있습니다.

## 동작하는 기능

- **실시간 영업 상태** — 방문자의 현재 시각을 요일별 영업시간과 비교해
  `영업 준비 중 / 지금 영업 중 / 라스트오더 마감 / 영업 종료`를 자동 표시하고,
  영업시간표에서 오늘 요일을 강조합니다. 1분마다 갱신됩니다.
- **계절 메뉴 전환** — 접속한 달에 맞는 계절이 기본 선택되고,
  탭을 누르면 메뉴와 함께 **사이트 전체 강조색이 그 계절 색으로 바뀝니다.**
  (봄 분홍 · 여름 청록 · 가을 호박빛 · 겨울 대추빛)
- **사계절 마크** — 로고의 원이 네 개 호로 나뉘어, 현재 계절 호에만 색이 들어옵니다.

## 실제 의뢰에서 바꾸는 곳

| 바꿀 것 | 위치 |
|---|---|
| 계절 메뉴 이름·가격·설명 | `assets/js/cafe.js` 상단 `SEASONS` 객체 |
| 영업시간 · 휴무일 | `assets/js/cafe.js` 의 `HOURS` + `index.html` 영업시간표 |
| 상호 · 주소 · 연락처 | `index.html` (헤더 / 오시는 길 / 푸터) |
| 상시 메뉴 가격 | `index.html` 의 `.price-list` |
| 좌석 도면 | `index.html` 의 `.plan` SVG (사각형·원 좌표만 수정) |
| 지도 위치 | `index.html` 의 지도 `iframe` 좌표 (`q=위도,경도`) |
| 계절 색 | `assets/css/cafe.css` 상단 `[data-season="..."]` 토큰 |

### 사진을 넣을 때

지금은 사진 없이 타이포그래피와 좌석 도면만으로 구성되어 있습니다.
실제 매장 사진이 준비되면 히어로(`.hero`)와 공간(`.plan-grid`) 자리에
`<img>` 또는 `background-image`로 얹으면 됩니다. 레이아웃은 그대로 유지됩니다.

## 배포 후 확인할 것

- 지도 `iframe`이 실제 주소를 가리키는지
- 휴대폰에서 하단 고정 바가 콘텐츠를 가리지 않는지 (푸터 하단 여백 확보됨)
- 영업시간을 바꾼 뒤 영업 상태 문구가 맞게 나오는지
