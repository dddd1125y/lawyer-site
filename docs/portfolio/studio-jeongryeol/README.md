# 스튜디오 정렬 — 필라테스 스튜디오 홈페이지 데모

크몽·숨고 포트폴리오로 쓰기 위해 만든 **1페이지 필라테스 스튜디오 홈페이지 데모**입니다.
"스튜디오 정렬"은 실제로 운영되는 스튜디오가 아니라, 필라테스·요가·PT 스튜디오 홈페이지가
어떤 모습이어야 하는지 보여주기 위해 만든 가상의 매장입니다.
(페이지 곳곳에 데모임을 명시해 두었습니다.)

빌드 도구 없이 HTML·CSS·바닐라 JS만 사용하므로 파일을 그대로 올리면 바로 서비스됩니다.

```
portfolio/studio-jeongryeol/
├── index.html                  전체 페이지 (8개 구획)
└── assets/
    ├── favicon.svg             정렬 마크 (척추선 + 정렬 바)
    ├── css/studio.css          제도 도면 스타일 + 레벨 색 토큰
    └── js/studio.js            ★ 시간표 데이터 + 실시간 수업 상태
```

## 왜 이 업종인가

카페 다음으로 소상공인 홈페이지 수요가 큰 업종입니다. 그런데 대부분의 스튜디오가
**주간 시간표를 엑셀 캡처 이미지로 올려 둡니다.** 모바일에서 확대해야 읽히고,
수업 하나 바뀔 때마다 이미지를 다시 만들어야 하고, 검색에도 안 잡힙니다.

이 데모의 핵심 주장은 하나입니다 — **시간표를 이미지가 아니라 데이터로 관리하면,
한 곳만 고쳐도 웹·모바일이 같이 바뀌고 "지금 무슨 수업 중인지"까지 자동으로 나온다.**

## 화면 구성

| # | 구획 | 목적 |
|---|---|---|
| 01 | 헤더 | 스크롤해도 상호와 메뉴가 따라옴 |
| 02 | 히어로 | **지금 어떤 수업이 진행 중인지**를 첫 화면에서 즉시 확인 |
| 03 | 소개 | 정원을 5명으로 묶어 둔 이유 = 등록 동기 |
| 04 | **주간 시간표** | 페이지를 반전시킨 어두운 구획. 레벨 필터 + 오늘 강조 + 진행 중 표시 |
| 05 | 수업 종류 | 기구/매트 구분 + 레벨을 리포머 스프링 색으로 설명 |
| 06 | 강사 | 사진 없이 자격증·전문 분야로 신뢰 확보 |
| 07 | 회원권 | 횟수제 가격표 + **법정 환불 규정** |
| 08 | 오시는 길 | 지도 + 요일별 운영시간 + 주차 + 시설 |
| — | 제작사 밴드 | WEB·BUILD 소개 · 가격/기간 안내 |

모바일에서는 화면 하단에 **"시간표 / 회원권·체험"** 고정 바가 항상 붙어 있습니다.

## 동작하는 기능

- **실시간 수업 상태** — 방문자의 현재 시각을 시간표와 비교해 네 가지 상태를 자동 표시합니다.
  - 수업 중 → `지금 「리포머 상급」 수업 중 · 20:20에 끝납니다`
  - 1시간 이내 → `다음 수업까지 20분 · 오늘 19:30 리포머 상급`
  - 종료 후 → `오늘 수업이 모두 끝났습니다 · 내일 07:00 리포머 입문`
  - 휴무일 → `오늘은 휴무입니다 · 월요일 07:00 모닝 매트 입문`

  1분마다 갱신되고, 시간표에서도 **진행 중인 수업 칸이 파란색으로 바뀝니다.**

- **레벨 필터** — 입문/중급/상급/개인을 눌러 해당 레벨만 볼 수 있습니다.
  필터 결과가 없는 요일에는 "해당 레벨 없음"이 표시됩니다.

- **오늘 요일 강조** — 데스크톱에서는 오늘 열의 배경이 밝아지고,
  모바일에서는 **오늘 요일이 기본 선택**되어 열립니다.

- **반응형 시간표** — 데스크톱은 7열 그리드, 900px 미만에서는
  요일 탭 + 하루치 세로 목록으로 전환됩니다. (7열을 휴대폰에 억지로 욱여넣지 않습니다.)

## 실제 의뢰에서 바꾸는 곳

| 바꿀 것 | 위치 |
|---|---|
| **시간표 전체** | `assets/js/studio.js` 상단 `SCHEDULE` 객체 ← 여기만 고치면 됩니다 |
| 수업 1회 길이 | `assets/js/studio.js` 의 `DURATION` (기본 50분) |
| 레벨 이름 | `assets/js/studio.js` 의 `LEVELS` |
| 레벨 색 | `assets/css/studio.css` 상단 `--lv1` ~ `--lv4` (밝은 면/어두운 면 한 쌍) |
| 상호 · 주소 · 연락처 | `index.html` (헤더 / 오시는 길 / 푸터) |
| 강사 프로필 | `index.html` 의 `.teachers` |
| 회원권 가격 | `index.html` 의 `.price-table` |
| 환불 규정 | `index.html` 의 `.notice` |
| 운영시간표 | `index.html` 의 `.hours-table` |
| 지도 위치 | `index.html` 의 지도 `iframe` 좌표 (`q=위도,경도`) |

### 시간표 한 줄 추가하는 법

```js
// 키 0=일 1=월 2=화 3=수 4=목 5=금 6=토
3: [
    { s: '07:00', n: '모닝 매트', lv: 1, t: '지원' },
    //   ↑시작    ↑수업명        ↑레벨   ↑강사
]
```

종료 시각은 `DURATION`으로 자동 계산되므로 적지 않습니다.
휴무일은 빈 배열 `[]`로 두면 시간표에 "휴무"가 표시됩니다.

### 사진을 넣을 때

지금은 사진 없이 타이포그래피와 정보 구조만으로 구성되어 있습니다.
실제 스튜디오 사진이 준비되면 히어로와 수업 종류(`.classes`) 자리에
`<img>`를 얹으면 됩니다. 강사 카드의 모노그램(`.mono-badge`)은
프로필 사진으로 교체하기 좋게 정사각형으로 잡아 두었습니다.

## 법적 고지 관련

필라테스·헬스장은 **「체육시설의 설치·이용에 관한 법률」** 적용을 받아
환불 규정을 고지해야 하고, 분쟁 시 공정거래위원회 소비자분쟁해결기준이 적용됩니다.
`.notice` 구획에 이를 반영한 6개 항목이 들어 있습니다.
실제 의뢰에서는 **반드시 해당 스튜디오의 실제 약관으로 교체**해야 합니다.

## 배포 후 확인할 것

- 지도 `iframe`이 실제 주소를 가리키는지
- 시간표를 바꾼 뒤 히어로 상태 문구가 맞게 나오는지 (수업 중 / 다음 수업 / 휴무)
- 휴대폰에서 하단 고정 바가 콘텐츠를 가리지 않는지 (푸터 하단 여백 확보됨)
- 사업자등록번호·통신판매업신고번호를 실제 값으로 채웠는지
