처음 연락부터
완성까지, 4단계

맡기고 나서 “지금 어디까지 됐지?” 궁금해지지 않도록, 각 단계에서 무엇을 하고 무엇을 받게 되는지 먼저 알려드립니다.

01

요구사항 파악

어떤 사업을 하시는지, 사이트로 무엇을 이루고 싶으신지 편하게 이야기 나눕니다. 참고하고 싶은 사이트나 원하는 분위기가 있다면 이 단계에서 함께 모읍니다. 아직 정리가 안 된 상태여도 괜찮습니다. 질문을 드리면서 같이 정리해 나갑니다.

기간
1~2일
드리는 것
요구사항 정리 문서
필요한 것
사업 소개 · 참고 사이트
02

구조 설계

어떤 페이지가 필요하고 각 페이지에 무슨 내용이 들어갈지 사이트맵으로 정리합니다. 방문자가 헤매지 않고 원하는 정보에 닿도록 화면의 흐름을 먼저 설계합니다. 이 단계에서 방향을 확정하면 이후 수정이 훨씬 줄어듭니다.

기간
2~3일
드리는 것
사이트맵 · 화면 구성안
확인하실 것
페이지 구성과 순서
03

디자인 · 개발

정해진 구조 위에 실제 화면을 디자인하고 코드로 구현합니다. 다 만든 다음에 한 번에 보여드리지 않고, 작업 중인 화면을 계속 공유해 완성되기 전에 방향을 바로잡을 수 있게 합니다.

기간
범위에 따라 상이
드리는 것
실제로 열어볼 수 있는 사이트
공유 주기
주요 화면 완성 시마다
04

피드백 반영

완성본을 직접 확인하시고 고치고 싶은 부분을 자유롭게 말씀해 주시면 됩니다. 횟수를 세지 않고 만족하실 때까지 반영합니다. 최종 확인 후에는 파일과 접속 정보를 정리해 넘겨드리고, 이후 생기는 문제도 함께 봅니다.

✓ 추가 비용 사전 안내범위를 벗어나면 미리 말씀드립니다
