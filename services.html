필요한 만큼,
정확하게

전부 다 하는 대신, 맡은 범위를 확실하게 끝내는 쪽을 택합니다. 아래 네 가지가 주로 의뢰받는 작업입니다.

01

반응형 웹사이트 디자인

휴대폰에서 열었을 때 글자가 잘리거나 버튼이 눌리지 않는 사이트를 만들지 않습니다. 가장 작은 화면부터 설계해 큰 화면으로 넓혀가는 방식으로 작업합니다.

모바일 우선 설계 타이포그래피 정리 접근성 고려
02

기능 구현

보이는 화면만이 아니라 실제로 동작해야 하는 부분을 만듭니다. 문의 폼, 지도, 예약 링크, 외부 서비스 연동처럼 손이 가는 작업을 맡습니다.

문의 · 신청 폼 API 연동 간단한 관리 화면
03

홈페이지 · 포트폴리오 제작

사업 소개, 개인 포트폴리오, 브랜드 랜딩 페이지처럼 “보여주는 것”이 목적인 사이트를 구성부터 함께 정리해 만듭니다. 어떤 내용을 넣을지 막막해도 괜찮습니다.

사업 홈페이지 포트폴리오 랜딩 페이지
04

수정 · 유지보수

이미 있는 사이트를 손보는 일도 맡습니다. 디자인만 다듬는 작업, 기능 하나 추가, 깨진 화면 수정처럼 규모가 작은 요청도 환영합니다.
